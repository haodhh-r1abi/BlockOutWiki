Mô tả

  • Game chạy hai hệ cấu hình từ xa song song: Firebase Remote Config (37 model, cache ở Configs/CachedRemoteConfigs) và một hệ riêng của studio gọi là Grand Config (cache ở GrandConfigs/GrandCached*).
  • Với một số cấu hình quan trọng — quảng cáo, Play On, bảng màn — bản Grand thắng bản Firebase khi cờ FromBackend được bật.
  • Đây là lý do chỉ đọc file mặc định trong APK sẽ cho kết luận sai về game.

Còn thiếu / chưa xác minh

📌 1.636 khoá chỉ server gửi chưa được giải nghĩa hết — phần lớn thuộc các sự kiện đang tắt.
📌 15 khoá Firebase mà client không có model (MiniGame, EndlessPortal, LoopLevels, AppsFlyer…) là di sản template sao từ Magic Sort — đã ghi lại đầy đủ trong appendix/remote-config-full.md nhưng không dùng được cho Block Out.
📌 Ba mục abt_experiments_key / personalization_metadata_key / rollout_metadata_key đều trống trên tài khoản thử nghiệm, nên chưa quan sát được A/B test thật nào.

Mở khóa & điểm vào

Luôn hoạt động.

Điểm vào:

  • Khởi động app
  • Sau khi đăng nhập
  • Khi phân khúc hoặc CPM thay đổi

Cách hoạt động

  1. Client đóng sẵn 39 file mặc định trong Resources/defaultconfigs.
  2. Khi chạy, Firebase Remote Config tải bản mới và FirebaseConfigPersistenceService cache xuống Configs/CachedRemoteConfigs.
  3. Song song, GrandConfigPersistenceService và GrandRemoteConfigRemoteService lấy cấu hình từ backend của studio, cache vào thư mục GrandConfigs với ba file: GrandCachedAdConfig, GrandCachedPlayOnConfig, GrandCachedRemoteLevelConfigs.
  4. Mỗi cặp cấu hình có một model điều phối kết thúc bằng 'FromBackend' (AdConfigModelFromBackend, PlayOnConfigModelFromBackend) mang hai trường IsEnabled và ConfigType; IsEnabled quyết định bản Grand có thắng bản Firebase hay không, ConfigType là số hiệu biến thể mà backend chọn cho tài khoản này.
  5. Mẫu cài đặt giống hệt nhau ở AdConfigService và PlayOnConfigService: cùng hằng CachedDirectoryName = 'GrandConfigs', cùng bộ hàm Cache / LoadCachedConfig / IsCached / DeleteCachedConfig.
Luồng chi tiết theo code

Client đóng sẵn 39 file mặc định trong Resources/defaultconfigs. Khi chạy, Firebase Remote Config tải bản mới và FirebaseConfigPersistenceService cache xuống Configs/CachedRemoteConfigs. Song song, GrandConfigPersistenceService và GrandRemoteConfigRemoteService lấy cấu hình từ backend của studio, cache vào thư mục GrandConfigs với ba file: GrandCachedAdConfig, GrandCachedPlayOnConfig, GrandCachedRemoteLevelConfigs. Mỗi cặp cấu hình có một model điều phối kết thúc bằng 'FromBackend' (AdConfigModelFromBackend, PlayOnConfigModelFromBackend) mang hai trường IsEnabled và ConfigType; IsEnabled quyết định bản Grand có thắng bản Firebase hay không, ConfigType là số hiệu biến thể mà backend chọn cho tài khoản này. Mẫu cài đặt giống hệt nhau ở AdConfigService và PlayOnConfigService: cùng hằng CachedDirectoryName = 'GrandConfigs', cùng bộ hàm Cache / LoadCachedConfig / IsCached / DeleteCachedConfig.
