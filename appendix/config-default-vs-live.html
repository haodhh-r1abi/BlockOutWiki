Config: mặc định trong client vs bản server đang chạy

Client đóng sẵn 39 file trong Resources/defaultconfigs/. Khi chạy, game tải bản server về và cache lại trên bộ nhớ ngoài của máy (Configs/CachedRemoteConfigs cho Firebase Remote Config, GrandConfigs/GrandCached* cho cấu hình lấy thẳng từ backend). Bảng dưới so từng khoá một, kể cả khoá lồng trong mảng/object.

Tên khoá so theo kiểu bỏ qua hoa/thường vì hai bên đặt khác nhau (PlayOnPrice ở client, playOnPrice ở server).

Cột Khác cách ghi là những khoá cùng giá trị nhưng ghi khác kiểu — enum client ghi bằng tên ("Consumable", "Duration") còn server gửi số thứ tự (0, 2), hoặc 2 vs 2.0, hay "00.00:30:00" vs "00:30:00". Đây không phải thay đổi thiết kế.
