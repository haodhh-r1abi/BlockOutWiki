Về tài liệu này

Nguồn dữ liệu

  • APK Block Out! 1006 (package com.grandgames.catblockjam, Android arm64-v8a, Unity 2021.3.57f2 IL2CPP). Asset và stub C# dựng bằng AssetRipper 2.0; logic native khôi phục bằng Il2CppDumper + Ghidra 12.1.3 → 2.456 file pseudo-C, 27.641/28.134 method đọc được (98,2%).
  • Máy chạy thật: hai lần kéo dữ liệu (14/09 và 15/09/2026) từ LDPlayer qua adb — cấu hình server đã cache, save game, bảng xếp hạng, bộ màn tải thêm, asset bundle.

Không có request nào được gửi tới hệ thống của studio. Mọi dữ liệu server ở đây là bản game tự tải về rồi cache lại trên máy. Các khoá định danh hoặc bí mật (ClientKey web shop, SDK key AppLovin, user id, device id) đã được che.

Đọc sao cho đúng

  • Đừng chỉ đọc config trong APK. Game chạy hai hệ cấu hình từ xa song song; với quảng cáo, Play On và bảng màn thì bản backend (GrandConfigs/) thắng bản Firebase. Có 61 khoá server thực sự ghi đè giá trị mặc định — xem trang Client vs server. Ví dụ: giá Play On thật là 900 / 1.900 / 2.900 coin chứ không phải 900/900/900; quảng cáo xen kẽ không chạy vì server đặt firstLevelToShowInter = 10000 trong khi game chỉ có 999 màn.
  • Mỗi use case có cột Evidence là tên method thật; mở file .c tương ứng trong RecoveredNative/PseudoC để đối chiếu.
  • Dòng ghi "server đang chạy" là giá trị lấy từ máy, không phải giá trị mặc định trong APK.

Dấu vết dùng chung với Magic Sort

Block Out! và Magic Sort cùng của Grand Games và chia sẻ khung Modules/Contexts/*. Trong client Block Out còn nguyên namespace magicsort.schemas.v1 (112 lớp FlatBuffers), các enum mang tên Bottle*, Cauldron*, MagicStreak*, Tower, EndlessPortal, và 15 khoá remote config của Magic Sort mà Block Out không có lớp nào để đọc. Ngay cả ảnh poster tải từ server cũng vẽ nhân vật chai của Magic Sort.

Cách cập nhật

  1. Sửa GameDesign/gdd/<Feature>.json theo gdd/SCHEMA.md.
  2. python tools/gd_bo_cfgmerge.py — bơm lại bảng config và đối chiếu client/server.
  3. python tools/gd_sitemeta.py rồi python tools/gd_site.py — sinh lại site/.
Tài liệu thiết kế đọc ngược từ client Block Out! 1006 đang cài và mã decompile 1006 (14/09/2026) · sinh tự động từ GameDesign/gdd/*.json bằng tools/gd_site.py · chỉ dùng nội bộ.
